# 内网打印服务 v3 · 使用说明

> 手机拍照 → 网页预览/调整 → 直接打印到连接这台电脑的打印机。
> 本版本修复了「手机上传图片打印太小 / 网页不能缩放」「别人能看到我的文件」「界面引导弱」三个问题，并优化了打印设置。

## 一、启动服务

1. 把 `PrintServer.exe` 放到一个你平时有写入权限的文件夹（例如 `D:\PrintServer\`）。
2. 双击运行。程序没有主窗口，会在**系统托盘**（任务栏右下角）出现一个蓝色打印机图标。
3. 鼠标**左键单击/双击**托盘图标 → 打开管理页面；**右键**菜单可查看：
   - 打开管理页面
   - 手机访问二维码（用手机扫一下就能打开）
   - 服务地址（例如 `192.168.1.5:5000`）
   - 开机自启：开启/关闭
   - 退出
4. 手机与这台电脑连**同一个 WiFi/局域网**，浏览器访问托盘菜单里的服务地址即可。

> 程序运行目录会自动生成 `uploads/`、`pdfs/`（上传与转换后的文件，1 小时后自动清理）、`print_log.txt`（打印日志）、`server.log`（运行日志）。

## 二、三步打印流程（手机 / 电脑通用）

### 第 1 步：上传文件

- 手机：点 **选择文件** 从相册/文件选择；点 **拍照上传** 直接调用相机拍摄。
- 电脑：拖拽文件到方框，或按 `Ctrl + V` 粘贴截图/文件。
- 支持：PDF、图片（JPG/PNG/BMP/GIF/TIFF）、文本（TXT/MD/LOG）、Office（DOC/DOCX/XLS/XLSX/PPT/PPTX），单文件最大 200MB。
- 上传后自动转换为 PDF，列表显示「已就绪 / 转换失败」。刷新页面文件不会丢。

### 第 2 步：预览调整（解决「打印太小」）

- 页面预览支持 **滚轮 / 双指捏合缩放、拖动、双击放大**，工具条有 −、百分比、+、适应窗口、100%。
- 图片文件右侧有「图片布局」：
  - **适应页面**（默认）：完整显示整张照片，四周留白，不会裁掉内容；
  - **铺满页面**：按比例放大铺满整张纸，居中裁掉少量边缘——**手机照片想要打满整页选这个**；
  - **原始大小**：按照片自身尺寸打印。
  - 还可以旋转 0/90/180/270°、调整页边距、纸张（A4/A5/Letter/4R/5R）、纸张方向。

### 第 3 步：打印设置

- **打印机**：下拉选择，点「刷新」重新读取。（默认使用系统默认打印机）
- **份数** 1–10；**单双面**（单面/长边翻转/短边翻转）；**纸张**、**打印方向**、**打印质量**（普通/高质量）。
- **页码范围**：全部 / 奇数页 / 偶数页 / 自定义（如 `1-5, 7`），也可直接点页码按钮。
- **Excel 文件**：可选择工作表，并输入打印区域（如 `A1:F20`）或点「可视选区域」在表格里拖拽框选。
- 勾选「待打印文件」里的文件（可多选），点 **开始打印**。打印进度、每个文件成功/失败、本次打印记录都会显示在页面上。

> 提示：图片的纸张和方向以第 2 步设置为准；其他文件的方向/纸张在第 3 步设置。

## 三、隐私说明（本版重点修复）

- 每台手机/每个浏览器都有自己独立的会话：**只能看到、预览、打印、删除自己上传的文件和打印记录**，别人打开同一个网址看不到你的文件。
- 只有**运行服务的这台电脑本机**（局域网 IP 直接访问时为普通用户）打开网页时，才会显示「本机管理员」，可查看所有会话文件、一键清理全部。
- 清除浏览器数据或换浏览器后，会开始一个新的会话（之前上传的文件仍在服务器上，1 小时后自动清理）。
- 本服务面向可信局域网，请勿把端口暴露到公网；服务本身无登录、HTTP 明文。

## 四、常见问题

**Q：手机打不开网页？**
1. 确认手机和电脑在同一局域网（同一路由器/WiFi）；
2. 检查 Windows 防火墙：首次运行会弹窗询问，请勾选「专用网络」并允许；若没弹窗，可在「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里允许 `PrintServer.exe`；
3. 确认托盘菜单里的服务地址是否和电脑实际 IP 一致（多网卡/虚拟网卡时可能不同）。

**Q：双击后没反应/没看到托盘图标？**
看 exe 同目录的 `server.log`；也可能是端口 5000 被占用（会弹窗提示）。退出占用的程序，或在快捷方式里加参数 `--port 5001` 换端口（服务地址随之变化）。

**Q：上传 Office 文档一直「转换中」或失败？**
需要电脑安装了 Microsoft Office、WPS Office 或 LibreOffice 之一。第一次 Word/Excel 启动会自动创建 COM 进程，可能需要 10–30 秒，请耐心等待。

**Q：点开始打印没反应/报错？**
- 确认打印机已开机、联机，打印队列里没有卡住的任务；
- 该打印机是否被设为默认/是否在列表里；
- 「高质量」会慢一些；纸张/双面若打印机驱动不支持，会自动回退默认设置（页面上会有提示）。

**Q：打印图片有白边 / 被裁切？**
白边：第 2 步选「铺满页面」；被裁切：选「适应页面」或减小旋转角度（照片方向不对时先旋转）。

**Q：文件会一直留在电脑上吗？**
不会。上传文件与转换 PDF 默认 1 小时后自动清理，也可在第 3 步「清空我的文件」或管理员「清理全部会话文件」立即删除。

**Q：杀毒软件报毒？**
本程序是 PyInstaller 打包的 Python 程序，未签名，部分杀软会误报。可添加信任；介意的话可用源码自行运行/打包（见下）。

## 五、从源码运行 / 重新打包

源码在发布包的 `源码\` 目录（`print_server.py` + `static/`）：

```powershell
cd 源码\PrintServer
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe print_server.py --port 5000          # 源码运行
powershell -ExecutionPolicy Bypass -File build.ps1             # 重新打包 exe
```
